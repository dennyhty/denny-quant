# 網路上公開的策略回測（2026-11-22，只做研究）

**結論：7 種、28 組設定沒有一種通過驗證門檻，實盤不用改。**

回測條件和其他研究一樣：時點幣池、扣手續費＋滑價＋資金費、2020–2023 樣本內、2024 起樣本外；每種的主設定只用樣本內挑。
出場測兩種：實盤出場（止損 1.5 ATR、1/3/5R 各平 1/4、追蹤）和 YouTube 常見的「止損 1.5 ATR、1.5R 全部出場」。
累計試過 1,890 組，嚴格群集 t 門檻 4.04。程式 `research/public_strategies.py`、`research/public_strategies_run.py`；明細 `reports/signals/public_strats_*_20261122.csv`。

## Denny 在看的兩個 TradingView 指標

截圖裡的通道（EMA 12、144/169、288/338、576/676）在 2026-11-20 已測過（report_vegas_params_20261120.md），這次測它多出來的部分。
200 均線的種類與長度、HMA 長度截圖看不到，用常見預設（SMA/EMA 200、HMA 55、SAR 0.02/0.2）。

| 加在實盤維加斯上的條件 | 拿掉多少單 | 結果 |
|---|---|---|
| 只做 SMA200 同方向 | 約 2–3% | 幾乎沒差（4H 樣本外 +0.066 → +0.068R），被拿掉的單也沒有比較差 |
| 只做 EMA200 同方向 | 0 筆 | 完全沒作用：維加斯要求收盤在 144/169 通道外，EMA200 幾乎一定在同一邊 |
| 「只做趨勢單」：HMA 同方向＋SAR 同方向 | 約 60% | 2H 樣本外變好（+0.060 → +0.150R），但 4H 樣本外變差（+0.066 → −0.022R）；方向不一致、樣本只剩 1,000–2,000 筆，也沒過鄰近參數檢查，不建議採用 |

MACD 指標的背離（一般／雙重／延伸）屬於 10 月已否決的背離類，不重測；它的金叉死叉配 200 均線見下表第一列。

## 沒測的與原因

超級趨勢、一目均衡表、SAR、唐奇安、肯特納、布林、HMA、RSI/MACD 背離、Squeeze 都在 2026-10 測過（report_basic_indicators_*_20261013.md）。
GitHub 上的 freqtrade 熱門策略多半是 5 分鐘級的均值回歸短線，以我們的滑價與手續費假設一定被成本吃光，沒有測。
