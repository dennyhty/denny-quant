# 新策略搜尋（2026-11-22，只做研究）

**結論：4 類、17 組事先登記的設定，沒有一類通過驗證門檻，不建議加到實盤。**

- 回測條件：時點幣池（每月取上個月成交額前 100 名的幣安 USDT 永續）、每邊手續費 0.05%、依成交額分級的滑價、歷史資金費率；
  樣本內 2020–2023、樣本外 2024 起；每類的主設定只用樣本內挑。
- 驗證門檻：累計試過 1,862 組設定，嚴格群集 t 要 ≥ 4.04、Deflated Sharpe ≥ 0.95，另外要贏過隨機進場、鄰近參數也要正、和維加斯相關性低、拿掉最好的幣／年份後仍為正。
- 程式：`research/new_strategies_run.py`、`research/new_xsec.py`；明細 CSV：`reports/signals/new_strategies_{grid,gate,corr,yearly}_20261122.csv`。

## 1. 每週多空組合（對 BTC 中性）：4 種新排名

每週一再平衡，做多分數最高的 20%／30%、做空最低的，用 BTC 對沖掉 beta。

| 排名方式 | 想法 | 樣本內 平均 R / t | 樣本外 平均 R / t |
|---|---|---|---|
| fund7（資金費率高的做空） | 擁擠多單會吐回來，且做空收資金費 | +0.041 / 3.50 | −0.003 / 0.10 |
| rev7（近一週漲最多的做空） | 短期反轉 | −0.017 / −0.80 | −0.037 / −2.40 |
| resrev7（扣掉 BTC 後的反轉） | 個幣超漲超跌回歸 | −0.023 / −1.46 | −0.048 / −3.15 |
| max30（近 30 天暴漲過的做空） | 樂透幣效應 | −0.003 / −0.67 | +0.014 / −0.04 |

（上表為 q=0.2；q=0.3 結果方向相同。）

- 最有希望的是 fund7，但**樣本外歸零**：嚴格 t 1.97（要 4.04）、Deflated Sharpe 0.20（要 0.95）。
- 拆開看，fund7 樣本外的價格部分是虧的（不含成本的價格夏普 −0.78），帳面接近 0 只是靠收資金費撐住。2020–2023 的價格效果沒有延續到 2024 之後。
- 反轉兩種在樣本外反而明顯虧：加密貨幣週線上強者恆強多於反轉。

## 2. 資金費率極端時反向進場（單一幣、日線）

3 天平均資金費率（每 8 小時）> 0.05%／0.1% 做空、< −0.03%／−0.05% 做多；出場用「1R 平一半＋追蹤」或「持有 5 天」。
4 組設定樣本內、樣本外全部是負的（主設定樣本外 −0.029R，t −1.40），也沒贏過隨機進場。做空那邊平均 −0.11R：資金費率很高的幣通常還會繼續漲。

## 3. BTC/ETH 的 CME 週末跳空回補

週五 21:00 到週日 22:00（UTC）漲跌超過 1%／2%／3% 就往回補的方向進場，目標週五收盤價，止損等距。
三組全部是負的（跳空 1% 那組樣本外 −0.215R），跳空 3% 的筆數只有 170 筆也不夠。「CME 缺口一定會補」在幣安永續上扣掉成本後不成立。

## 4. 一天中特定時段的漲跌規律

用樣本內找出平均漲最多／跌最多的 3 個小時，樣本外在那幾個小時做多／做空。每筆都大虧（樣本外約 −0.15R），
因為每小時的平均漲跌只有幾個 bp，進出一次的手續費加滑價就把它吃光了。

## 和維加斯的關係

四類和維加斯的日報酬相關都很低（−0.11～+0.09），分散效果本來是有的，但它們自己沒有正報酬，所以合併後沒有幫助。

## 不要再試

以上 4 類、包括換參數的版本，都不建議再重跑。加上之前已否決的（網格、資金費率套利、日線突破、橫斷面動能／低波動、波動收縮突破、SMC、訂單流、RSI/MACD 反轉、諧波、外包日、美股合約、維加斯其他週期與參數、擴大幣池），
目前資料下能找到的「價格＋資金費率」型策略大多已經試過。之後若要再找，比較有機會的方向需要新的資料來源（例如鏈上數據、代幣解鎖時程、清算資料）。
